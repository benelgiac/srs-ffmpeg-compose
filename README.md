# srs-ffmpeg-compose

Simple application with two services:
- an instance of SRS streaming server with default settings
- an ffmpeg service pushing sample content to srs via rtmps

The main goal is to generate a sample HTTP-FLV stream for testing purposing.

This strictly follows the instructions provided by SRS https://github.com/ossrs/srs on how to run an SRS docker-based image and use ffmpeg to push a sample content.

# Usage

If your local 80 port is busy, define a different SRS_PORT in the .env file.

Run "docker compose up -d".

Access the stream generated by SRS at

- http://localhost/live/livestream.flv for HTTP-FLV format
- http://localhost/live/livestream.m3u8 for HLS format
- rtmp://localhost/live/livestream for RTMP format
